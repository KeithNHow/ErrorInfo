# Function Management
Codeunit contains three procedures that demonstrate different ways of using the ErrorInfo data type to show error messages with custom titles, messages, and actions. 

The DoSomething proc shows how to create an error message with a custom title and message, and add a navigation action to it. 
The DoSomething2 proc shows how to create an error message that navigates to a specific page without needing to specify a record. 
The DoSomething3 proc shows how to combine a navigation action with a custom action in the same error message.
